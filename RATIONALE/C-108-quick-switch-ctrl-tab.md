# C-108 会话快速切换改为 Ctrl+Tab 唤出的居中浮层，不占用宿主任何槽位

日期: 2026-11-11

#### 上下文
东家 2026-11-11 先提出「在会话标题行加一个快速切换入口」，据此已实现一版挂在 `conversation.session.header.lineage` 槽的标题栏切换器（零宽让位、hover/click 双态、body portal 下拉）。随后东家改变方向（同日，第二条指令）：改为 Alt+Tab 手感的快捷键唤出，并明确「删掉标题栏 chevron，只留快捷键」。键位在东家给出的三个候选里选定 `Ctrl+Tab`（`Alt+Tab` 被系统窗口切换占用，页面收不到）。

两条硬约束叠加：一是本 fork 需要持续合并上游，改动应尽量新增、少改既有行；二是「验证策略：全手动」，不挂自动门禁、不主动跑测试。

lineage 槽方案的既有成本在实施中已实证：该槽是 single 槽且动态包后注册必然成为 winner，本插件注册即遮蔽宿主 `dsh-client-ui-subagent` 的子代理切换器与子会话计数；为不遮蔽，又必须按「替换语义 / 追加语义」分支只渲染标题，实现复杂度与上游漂移风险都集中在宿主 DOM 细节上（`.crumb` 几何、`display: contents` 的槽 outlet、`openTitle` 祖先跳转）。

#### 决策
1. 入口形态从「标题栏槽内触发器」改为「全局热键唤出的居中浮层」：不注册任何宿主槽位、不查找 `slots` 服务、不读写标题行与面包屑——宿主标题区的一切（含宿主的子代理切换器）保持原样，从根上消除遮蔽与几何复刻的负担。
2. 键位 `Ctrl+Tab`：按住 Ctrl 连按 Tab 向后循环、`Ctrl+Shift+Tab` 向前，松开 Ctrl 即跳转到高亮项；Esc 取消；刚唤出还没按过 Tab 时高亮为 -1，松手不跳转。这是 Alt+Tab 的肌肉记忆，用户无需学习新的确认动作。
3. 监听用捕获期 `document` 级 `keydown` + `keyup`，唤出时 `preventDefault`/`stopPropagation`，避免宿主或浏览器把 Tab 当焦点转移先消费；`Alt`/`Meta` 同时按下时不触发，避免与系统快捷键混淆。
4. 循环高亮只写 `data-active`/`aria-selected` 属性并 `scrollIntoView({ block: "nearest" })`，**全程不调用 `focus()`**——焦点留在宿主输入框，松手即跳转。抢焦点会让「按住—循环—松手」的手感断掉（焦点每帧跳动、输入框失焦）。
5. 实现整体外提到独立文件（`quick-switch.mjs`），以工厂 `createQuickSwitch(deps)` 导出、依赖全部经入参注入；客户端运行时只保留五个接入点（样式并入、构造、publish、connect、dispose）。构建脚本在拼接时把该文件并入同一工厂作用域，staged 一致性检查的输入清单同步登记。
6. 候选不新造判定：core `switchCandidates` 只做「收 running/awaiting 主会话 → 排除当前 → 三分段」，排序原样沿用 `buildEntries`。**不套用 `classifyActiveEntries`**——它不把错误提醒归入任何组，套用会让出错会话在浮层里静默消失，与东家「blocked/error 也进」的口径冲突。
7. 第二行只读既有日志窗口派生的 `detail.previews.userPreview`，**绝不**把候选加进预览兜底集合（那会触发日志分页深翻，违背 R-01-025 的档位资源纪律）。不可得时整行 `hidden`，只留标题行。
8. 面板底色取不透明的主题实心底，不沿用宿主菜单面别名：宿主的菜单面颜色本身带约七成透明度（半透明菜单面），当作面板底会让背后内容透出来、整块发灰；面板是浮在正文之上的承接面，必须实心。面板宽度一并放大到接近宿主对话框的口径，字号与行高同步上调，避免窄面板显得局促。
9. 候选**包含当前会话**，但只作为取消出口：它不进 `switchCandidates` 的三段分组（那里仍排除自身，跳转目标集合不受污染），而由 `currentId` 与标题现场合成一行、单列末组，行上带空心圈与「当前」角标；循环序列里排在全部可跳转项之后，首按 Tab 不会白停在自身。提交命中自身时只收起、不走跳转通道——东家反馈「不含自身就没办法取消」，这是不必依赖 Esc 的取消路径。
10. 面板内不再常驻快捷键说明条：常驻一行说明既占高度又容易过期，删除后热键手感靠一次性说明与文档承载。
11. 唤出与收起各配一段过渡，并用一个只服务退场的轻遮罩盖住「选中后到新会话画出来」的延时空档。落 `hidden` 用定时器而非 `animationend`：降低动效偏好下动画被整段关闭、动画事件永不触发，用事件收尾会让面板永久卡在可见态。遮罩 `pointer-events: none`，不引入点外关闭（沿用上文「被否方案」的同一禁用理由）。

12. 工作区标签与活动卡片同构：排在标题**之前**、与标题同处一行（不是行尾角标），并复用活动卡片那一套工作区颜色槽位——同一套自定义属性名、同一个纯函数按本帧候选身份集合解析、颜色公式留给样式侧在 OKLCH 空间计算。理由是同名会话在不同工作区下最容易混淆，标签的作用是**快速辨认归属**而不是补一条元数据；行尾灰色小字既难扫读、又和「当前」角标抢同一位置。取既有派生已算好的归属，空则整块隐藏、不为标签回查工作区数据。

#### 被否方案及原因
- 保留标题栏 `lineage` 槽入口（前一版实现）：要遮蔽宿主子代理切换器、要复刻宿主面包屑几何、要处理槽的替换/追加两种语义，冲突面全在宿主 DOM 细节上；东家改变方向后这些成本没有对价。
- 挂 `.actions` 或 `.corner`：同样是占用宿主槽位——`.actions` 溢出会裁剪并淡出（浮层必须再 portal 一次），`.corner` 是 single 槽会把既有控件顶掉。
- 劫持宿主标题 DOM 直插按钮：宿主每次重渲染都丢节点，需要常驻 MutationObserver 或定时重插守卫。
- `Alt+Tab`：被操作系统窗口切换抢占，页面收不到该事件，不可实现。
- 双击 Alt：避开组合键冲突，但手感与 Alt+Tab 差异大且易误触。
- 按一次弹出、↑↓ + Enter 确认（命令面板手感）：需要额外的确认动作，不符合东家选的「按住循环、松开确认」。
- 让浮层读取候选会话日志以补全第二行：直接违背 R-01-025 的档位资源纪律。
- 用 `document.addEventListener("click")` 做点外关闭：仓库断言禁止（`scripts/check.mjs` 明禁 document click 拦截）；本方案改为 Esc / 松手 / 点选行三条收起路径，不需要点外关闭。

#### 影响面
R-01-028 / 快捷切换器（新子系统条目）、活动状态模型（`switchCandidates` 纯函数）；实现落在独立的快捷切换器文件，构建脚本与 staged 一致性检查各加一处登记；不触碰宿主半与存储。已知平台限制：纯浏览器标签页里 `Ctrl+Tab` 被浏览器标签切换抢占、页面收不到该事件，桌面壳 webview 无标签栏时可用——东家已知悉并仍选定该键位。
